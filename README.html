CORAL coordination fork

Run teams of local Flint agents on ALE-Bench AHC039, and compare agents that compete with agents that cooperate.

Start a run

coral start -c examples/ale_bench_ahc039/task.yaml agents.mode=cooperate
coral ui --inference-url http://127.0.0.1:11501     # dashboard: localhost:8420
coral stop

Change any setting by adding name=value to coral start. The model server must be running first (see below).

The three main choices

  • Mode: in compete mode, agents only see each other's attempts and notes. In cooperate mode they can also send each other messages.
  • Loop: in agentic mode, each agent is a coding agent that edits, tests and submits with tools. In oneshot mode, each attempt is a single model call that writes the whole program.
  • Internet: off by default. Agents can then only reach the local model server.

Other features

  • Messages (cooperate): five types: message, finding, warning, request and reply. Agents receive them with their next result.
  • Status board (one-shot): each agent posts a one-line status, so the team can see who's working on what.
  • Team memory (one-shot): a background helper records a lesson from every attempt. Before each attempt it gives the agent a short brief of the most relevant lessons.
  • Subagents (agentic, off by default): agents only plan, and hand the actual work to Claude subagents on your subscription, with a spending cap.
  • Sandbox: each agent can only read and write its own workspace and the shared team files.
  • Dashboard: shows the team graph, each agent's live log and total tokens per second.

All settings

Values shown are those used by the AHC039 example.

agents.modecompetecompete or cooperate
agents.loopagenticagentic or oneshot
agents.count4number of agents
agents.internetfalsegive agents internet access
agents.sandbox.enabledtruesandbox agents (needed when internet is off)
agents.instructionsminimalminimal (short guide) or full (original long guide)
agents.researchfalsetell agents to research before coding
agents.memorytrueteam memory (one-shot only)
agents.memory_state_every8how often memory writes a team summary
agents.subagentsfalseplanner agents with Claude subagents (agentic only)
agents.subagent_max_running2subagents each agent can run at once
agents.subagent_run_budget_usd20spending cap for the whole run
agents.subagent_modelsonnetClaude model for subagents

Everything else is standard CORAL; see coral/config.py.

Model server

Flint runs on the local llama.cpp build in llama.cpp-flint, with four slots, one per agent:

env -u DYLD_LIBRARY_PATH llama.cpp-flint/build/bin/llama-server \
  -m flint-int4-q4_1.gguf --alias flint -ngl all -c 262144 -np 4 \
  --cache-ram 6144 --cache-ram-mlock -b 2048 -ub 512 \
  -fa on -ctk q8_0 -ctv q8_0 --jinja --port 11501

Benchmarks and the settings that were tried are in notes.md.

Comparing modes

CONDITIONS="oneshot:compete oneshot:cooperate" REPEATS=3 MINUTES=45 experiments/compare_modes.sh

Runs each condition in turn with a fresh model server and alternates the order on every repeat. Results go to results/experiments/.
